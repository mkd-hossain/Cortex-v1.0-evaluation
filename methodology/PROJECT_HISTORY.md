# v1 checkpoint and follow-up training history

The evaluated artifact is the released Keural Cortex 8B v1.0 checkpoint at `a592a43fe940299b5a025e5b719459cda97ae1e6`. Evaluation did not modify its weights.

According to the model author's account, a subsequent training effort was started and discontinued before completion because of available compute/resource limitations. This statement records author-provided project history; this evaluation is not an independent audit of that training effort. No dates, consumed compute, training steps, or resulting capability gains are asserted here.

The unfinished follow-up effort must not be confused with the evaluated v1 checkpoint or the completed 39-job evaluation. The evaluation itself initially reached its runtime deadline and later resumed with authorization, preserving completed results.

This repository concerns the final v1 evaluation. Earlier pilots and exploratory work remain available through Git history rather than appearing as current results.
