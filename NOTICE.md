# Licensing and provenance

This repository contains the completed v1 evaluation and its presentation. Model weights are not redistributed here; the released model is Apache-2.0 with applicable upstream notices. Dataset examples and third-party source retain their original licenses and terms. See frozen dataset metadata and `third_party/` for retained upstream license notices. No blanket license over third-party datasets or model-generated artifacts is implied.

The final-only repository layout changes presentation paths, not measured scores. Original run manifests describe original artifact locations and hashes; `SHA256SUMS` verifies this publication. Deployment account paths in public records were replaced with placeholders during the original publication. This repository does not reproduce private training rows, credentials, SSH keys, model weights or the private training checkout.
